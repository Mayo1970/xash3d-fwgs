## FAQ

**Q: How do I install the ports?**

**A:** Place **valve** [Half Life](https://store.steampowered.com/app/70/HalfLife/) and then depending on what you need inside **/dev_hdd0/data/xash3dfwgs/** (folder name must be **lowercase**)

If you want to run [Opposing Force](https://store.steampowered.com/app/50/HalfLife_Opposing_Force/), you will also need to add **gearbox**

If you want to run [Blue Shift](https://store.steampowered.com/app/130/HalfLife_Blue_Shift/), you will need to add **bshift** folder

If you want to run [Counter Strike](https://store.steampowered.com/app/10/CounterStrike/), you will need to add **cstrike** 

If you want to run [Team Fortress Classic](https://store.steampowered.com/app/20/Team_Fortress_Classic/), you will need to add **tfc**

**Q: I added the folders, but it doesn't work**

**A:** Please make sure that you're using the **Steam releases**. I can't guarantee that it will work with pak files or other copies. All the tests were done using Steam's 25th and legacy releases. **You have been warned**.

**Q: Are mods supported?**

**A:** Mileage may vary.

**Q: Are mouse and keyboard supported?**

**A:** Mouse is supported, keyboard has partial support. It may get added in future.

**Q: Why can't I connect to some Counter Strike servers?**

**A:** It's a protocol mismatch. It's not a problem tied to this port. Try another server.

**Q: Can I connect to GoldSrc servers?**

**A:** Yes, there's a [way](https://snmetamorph.github.io/posts/xash3d-fwgs-dec-2024/).

**Q: How do I open the menu on Counter Strike and Team Fortress Classic?**

**A:** Use D-pad up. Close with the same key. You can bind it from the settings.

**Q: How do I add bots on Counter Strike?**

**A:** You will need **BotChatter.db** and **BotProfile.db** from [Counter Strike: Condition Zero](https://store.steampowered.com/app/80/CounterStrike_Condition_Zero/) inside your **cstrike** folder as well as get the navigation files for the maps (you can look that up with a Google search). Once you set up both, you just load a map and write **bot_add** in the console. **Another device is suggested to host bots games**

**Q: I tried adding more than 7 bots but it doesn't work, why?**

**A:** That's the maximum amount of bots you can add with this port.

**Q: How can I add more than 7 bots?**

**A:** Use another device to host the server.

**Q: How can I connect to other servers even if they aren't listed?**

**A:** You type **connect <ip>** in the console.
